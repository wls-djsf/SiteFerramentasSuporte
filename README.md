## 🎯 Sobre o Projeto

O **Hub de Ferramentas de Suporte** foi desenvolvido para agilizar a rotina de profissionais de tecnologia e suporte técnico. Ele atua como um agregador que direciona o usuário exclusivamente para os **caminhos e portais oficiais** de cada software, garantindo downloads seguros, livres de malwares e sem intermediários ou links quebrados.

A interface foi desenhada com forte foco na experiência do usuário (UX), utilizando conceitos modernos de *Glassmorphism*, paleta de cores escuras (Dark Mode) e um sistema de clusterização para agrupar as ferramentas de forma lógica.

## ✨ Funcionalidades

- 🔍 **Busca em Tempo Real:** Filtre ferramentas instantaneamente por nome, categoria ou palavra-chave com feedback dinâmico.
- 🗂️ **Categorização Inteligente:** Layout em cascata (Masonry Grid) que agrupa lógicamente os softwares (Sistemas Operacionais, Acesso Remoto, Segurança, Utilitários e Produtividade).
- 📱 **100% Responsivo:** Layout fluido que se adapta perfeitamente a monitores desktop, tablets e smartphones.
- 🎨 **Design Moderno:** Interface baseada em *Glassmorphism* (efeitos de vidro e desfoque) para um visual limpo e redução do cansaço visual.
- 🔒 **Segurança em Primeiro Lugar:** Redirecionamento estrito para URLs oficiais das empresas desenvolvedoras.

## 📱 Instalação do Aplicativo (PWA)

Este projeto possui suporte a **PWA (Progressive Web App)**, permitindo que você instale o Hub diretamente no seu smartphone ou computador. Ele funcionará como um aplicativo nativo (em tela cheia e com ícone próprio), sem a necessidade de passar por lojas de aplicativos (Play Store ou App Store).

### 🟢 No Android (Google Chrome)
1. Acesse o site oficial pelo **Google Chrome**.
2. O navegador exibirá um banner na parte inferior: **"Adicionar à tela inicial"**. Clique nele.
3. Se o banner não aparecer, toque nos **três pontinhos (⋮)** no canto superior direito do navegador.
4. Selecione a opção **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**.
5. Confirme e o ícone do Hub aparecerá na sua gaveta de aplicativos.

### 🍎 No iPhone (iOS / Safari)
1. Acesse o site utilizando o navegador **Safari**.
2. Toque no ícone de **Compartilhar** (um quadrado com uma seta apontando para cima, localizado na barra inferior).
3. Role o menu para cima e selecione **"Adicionar à Tela de Início"** (Add to Home Screen).
4. Confirme clicando em **"Adicionar"** no canto superior direito.

### 💻 No Computador (Chrome / Edge)
1. Acesse a aplicação web pelo navegador.
2. Na barra de endereços (onde fica a URL), olhe para o lado direito (perto do ícone de estrela dos favoritos) e clique no botão de **Instalar**.
3. Confirme a instalação e o Hub abrirá em uma janela própria, livre das abas do navegador.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Variáveis de cor, CSS Grid (Grid Auto-Flow Dense), Media Queries e propriedades de `backdrop-filter`.
- **JavaScript (Vanilla):** Lógica otimizada de filtro de busca e manipulação de DOM.

## ⚙️ Como hospedar (Deploy)

Para que o site fique online de forma gratuita através do GitHub Pages, siga os passos abaixo:

1. Faça o *commit* do arquivo principal dentro do diretório `docs/` na branch `main`.
2. Acesse a aba **Settings** (Configurações) deste repositório.
3. No menu lateral esquerdo, clique em **Pages**.
4. Na seção *Build and deployment*, em *Source*, selecione **Deploy from a branch**.
5. Em *Branch*, escolha **`main`** e a pasta **`/docs`**.
6. Clique em **Save**.

O site ficará disponível no link oficial do repositório em poucos minutos.
